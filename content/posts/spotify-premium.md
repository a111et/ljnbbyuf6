1. Скачиваем официальный [Spotify](<https://www.spotify.com/us/download/windows/>)
2. Устанавливаем Spotify и закрываем его
3. Открываем Terminal или PowerShell от Администратора и вводим эту команду 

```
iex "& { $(iwr -useb 'https://raw.githubusercontent.com/SpotX-Official/SpotX/refs/heads/main/run.ps1') } -new_theme"
```

Есть аргумент для более тонкой настройки Spotify с помощью этого скрипта их можно узнать на GitHub по ссылке ниже. Аргументы добавлять через пробел после `-new_theme` 

Больше информации о этом тут 
<https://github.com/SpotX-Official/SpotX>
